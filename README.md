# 🧠 MindMitra
### AI-Assisted Cognitive Gaming and Memory Assistance Platform for Older Adults

MindMitra is an AI-assisted cognitive gaming platform designed to support older adults, particularly individuals experiencing memory difficulties and cognitive decline.

The platform provides interactive cognitive games and memory-based activities designed to encourage mental engagement, memory recall, attention, and cognitive stimulation through a simple and accessible interface.

## 🎯 Project Objectives

- Encourage regular cognitive engagement among older adults.
- Provide interactive memory-based games and activities.
- Make cognitive exercises accessible through a simple interface.
- Track individual activity performance and progress.
- Explore the application of Artificial Intelligence and Machine Learning in cognitive assistance.

## ✨ Key Features

- **User Profiles:** Individual profiles for maintaining separate activity records.
- **Memory Games:** Look-and-recall activities that encourage memory retention and recall.
- **Cognitive Activities:** Interactive exercises designed to stimulate different cognitive abilities.
- **Performance Tracking:** Displays activity results and performance.
- **Data Storage:** Stores individual profile results in separate files.
- **Elderly-Friendly Interface:** Large headings, high-contrast colours, clear buttons and simple instructions.
- **Accessible Gameplay:** Activities can be completed at an individual pace without mandatory timers.

## 🚀 Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/shankhin-s/MindMitra.git
```

### 2. Navigate to the Project Directory

```bash
cd MindMitra
```

### 3. Create a Virtual Environment

```bash
python -m venv .venv
```

### 4. Activate the Virtual Environment

Windows:

```bash
.venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
streamlit run app.py
```

The application will open in your default web browser.
